# MCPB manifest schema

`mcpb-manifest-v0.3.schema.json` is the published JSON schema shipped by `@anthropic-ai/mcpb` version 2.1.2, from the [MCPB repository](https://github.com/modelcontextprotocol/mcpb). Its MIT license is preserved as `MCPB-LICENSE`.

The build validates with AJV against this schema without installing the MCPB CLI's vulnerable development dependency tree. JSON-schema validation and packaged stdio smoke tests do not replace interactive Claude Desktop installation testing.
